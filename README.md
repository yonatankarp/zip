# Zip (moved)

This game now lives in **[yonatankarp/puzzles](https://github.com/yonatankarp/puzzles)**,
alongside Queens and whatever comes next, and is played at
**<https://yonatankarp.com/puzzles/>**.

`https://yonatankarp.com/zip/` serves a redirect to it. The redirect page also
retires the old service worker and its caches, so anyone who installed Zip to
their home screen stops being served the old app.

The sources here are kept for history. They are no longer built, tested or
deployed — see `site/` for everything that is still published. MIT licensed,
same as before.
